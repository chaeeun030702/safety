# 건설현장 안전문서 자동생성 플랫폼

현장사진 한 장을 올리면 위험 설명, 위험성평가표, 사전작업허가서(PTW), 안전포스터가 함께 만들어지는 다국어 웹사이트입니다.

- 연구: Database 기반 생성형 AI 활용 실시간 다국어 위험성평가표, 안전포스트 자동 웹생성 연구
- 충북대학교 안전공학과 이채은 · 지도교수 원정훈
- 참조 구조: https://e-safety.vercel.app

## 흐름

현장사진 → ④ 분석 엔진(AI 판독 또는 체크리스트) → RAG 검색(1~3단계 DB 46건) → ① 위험 설명·위험성평가표(A4 가로) → ② 사전작업허가서 PTW(A4 세로, KOSHA GUIDE P-94-2021) → ③ 안전포스터(A3 세로) → ChatGPT 추가작업

## 분석 엔진

| 모드 | 동작 |
|---|---|
| AI 판독 | `/api/read`가 Claude API로 사진을 보고 지식베이스 28항목 중 해당 항목, 위치(x·y), 빈도·강도, 근거(5개 언어)를 고릅니다. 근로자별 **안전모 착용 여부**를 따로 판독해 미착용자 수를 표시하고, '안전모 미착용' 항목(떨어짐·물체에 맞음)을 자동 선택합니다. |
| 체크리스트 자동 | 공종 태그(거푸집·단부·비계·보호구(안전모) 등 14종)를 누르면 관련 위험요인이 자동으로 체크됩니다. |
| 직접 선택 | 지식베이스 목록에서 직접 체크합니다. |

API 키가 없거나 판독에 실패하면 체크리스트 자동으로 바뀝니다.

사전작업허가서(PTW)의 체크리스트는 모두 직접 고칠 수 있습니다. □/■ 상자(필요 여부)·허가 종류·보충허가를 눌러 바꿀 수 있고, 항목 문구와 표 내용도 바로 수정됩니다. '해당 없음'으로 판정된 구간(가스농도 측정 등)도 흐리게 막지 않고 그대로 입력할 수 있습니다.

## 다국어

한국어만 · English · 中文 · Tiếng Việt · O'zbekcha 중에서 고릅니다. 위험성평가표와 PTW는 한국어가 위, 선택한 언어가 아래에 나옵니다. 안전포스터는 선택한 언어가 위, 한국어가 아래입니다.

## 폴더 구조

```
index.html          화면 (상단바 + 왼쪽 입력 패널 + 오른쪽 문서)
assets/app.js       생성 엔진 (지식베이스·RAG·평가표·PTW·포스터 연동)
assets/data.js      지식베이스 28항목, 다국어 사전, RAG 말뭉치 (자동 생성 파일)
assets/app.css      화면·인쇄 스타일
ptw.html            사전작업허가서 양식 (P-94-2021 별지 1·2 통합)
posters/*.html      안전포스터 양식 (3단계 ChatGPT 실사판, 사진 1 전용판)
samples/            예시 사진 1~3, 사진 1 ChatGPT 실사판
api/read.js         Vercel 서버 함수 — Claude 사진 판독
api/_kb.js          AI 판독용 지식베이스 목록
vercel.json         서버 함수 제한시간 60초
```

## Vercel 배포

1. 이 저장소를 Vercel에 연결합니다. 빌드 명령은 필요 없습니다(정적 파일 + 서버 함수).
2. Settings → Environment Variables에 다음을 넣습니다.
   - `ANTHROPIC_API_KEY`: Claude API 키 (넣지 않으면 사용자가 화면 ⑥에 자기 키를 넣어야 AI 판독이 됩니다)
   - `ANTHROPIC_MODEL`(선택): 기본값 `claude-sonnet-5-5`
3. 배포 후 `/api/read`를 열어 `{"ok":true,...,"key":true}`가 나오면 준비가 끝난 것입니다.

## 로컬 실행

```
npx vercel dev
```

서버 함수 없이 화면만 보려면 `python -m http.server`로도 열 수 있습니다. 이 경우에는 체크리스트 엔진으로 동작합니다.
