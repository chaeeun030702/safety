「Database 기반 생성형 AI 활용 다국어 위험성평가표, 사전작업허가서 자동 웹생성 연구」 — 건축공사·건축설비공사 4단계 산출물

3. 사전작업허가서(PTW) — A4 세로. 전기설비 표지(U01~U19)가 있으면 KOSHA GUIDE C-C-49-2026 전기 PTW, 건축·설비 표지(G01~G31)만 있으면 일반 건설 PTW. 모든 체크박스·칸을 고칠 수 있다
4. 다국어 안전포스터 — A3 세로, 외국어가 위·한국어가 아래

자동 생성 결과는 초안이다. AI는 최초 검토, 최종 판단은 관리감독자가 진행.

## 지식베이스 (체크리스트 50종)

| 구분 | 번호 | 내용 |
|---|---|---|
| 전기설비 | U01~U19 | 충전부·누전·정전 확인·가공전선 등 |
| 일반 건설 | G01~G20 | 개구부·안전대·비계·양중·굴착·거푸집·화기·밀폐 등 |
| 건축공사 추가 | G21~G25 | 거푸집 단부 타고 오르내림, 상하 동시작업, 비계 해체 순서, 이동식비계, 강풍 중 작업 |
| 건축설비 추가 | G26~G30 | 승강로·PIT 방호울 해체, 카 상부 안전대, 균형추 끼임(LOTO), 레일 양중 하부작업, 작업지휘자 미선임 |
| 관리 | G31 | 관리감독자 지휘·감시 부재, 다국어 TBM 없음 |

G21~G31은 1단계 건축공사·건축설비공사 재해 분석(CSI 건축 20,407건·설비 1,555건)에서 사망이 많은 작업을 골라 더했다. 법령 근거는 산업안전보건기준에 관한 규칙 원문(국가법령정보센터)과 대조했다.

## 표본 사진

상단 「표본 사진 ▾」에서 건설현장 사진 1~5와 전기설비 표본 1장을 고를 수 있다. 표본 판독 결과는 연구자가 확인한 AI 초안이다.

## 배포

Vercel 정적 사이트 + 서버리스 함수(`api/read.js` AI 사진 판독, `api/poster.js` 실사 포스터). 빌드 단계는 없다.
AI 판독을 서버에서 쓰려면 Vercel 환경변수 `ANTHROPIC_API_KEY`를 넣는다. 없으면 화면 ⑧에 키를 넣거나(이 브라우저에만 저장) 키워드 판독을 쓴다. 키 값은 저장소에 적지 않는다.

## 개인정보

이 저장소에는 개인 연락처·수신자 목록·메일/문자 발송 기능을 넣지 않았다. 올린 사진은 판독에만 쓰고 서버에 저장하지 않는다.
